Condiciones de uso

Estas condiciones describen el prototipo educativo actual y no constituyen asesoramiento jurídico. Deben revisarse si el sitio empieza a ofrecer servicios reales.

Carácter demostrativo

LudoVareia es un proyecto personal y educativo. El contenido del sitio tiene finalidad informativa.

El diálogo de donación es una simulación: no se procesa ningún pago ni se realiza ningún cargo.

Donación simulada

La cantidad seleccionada en el diálogo solo se utiliza para mostrar una confirmación visual. No se solicitan datos personales ni se realizan transacciones.

Contenido del sitio

Los textos y recursos se ofrecen con finalidad educativa e informativa. La disponibilidad y el contenido pueden cambiar. Si se incorporan servicios o funcionalidades que impliquen tratamiento de datos o transacciones, estas condiciones deberán actualizarse.
